Tutor IA — Opções

Provedor de IA

Cada provedor tem a sua chave, guardada só neste navegador (chrome.storage.local), sem sincronização, e enviada apenas para o servidor daquele provedor.

Google Gemini

Crie uma chave grátis em aistudio.google.com/app/apikey (botão Create API key) e cole aqui.

⚠ No plano grátis, o Google pode usar o conteúdo enviado (as perguntas e as respostas) para melhorar os produtos dele. Não envie dados pessoais ou sigilosos.

Anthropic Claude

Crie uma chave em platform.claude.com → API Keys. O uso é cobrado na sua conta da Anthropic.

Preferências

Leitura das páginas

Por padrão, o tutor só lê uma aba quando você clica no ícone da extensão, usa o menu de contexto ou o atalho. Se preferir que o botão Detectar na página funcione sempre, libere a leitura de todos os sites. A extensão só lê texto; ela nunca preenche, clica ou envia nada.

Página de teste

Cinco questões de exemplo (lógica, redes, segurança e Python, objetivas e dissertativa) para experimentar o menu Explicar com IA, o modo dica e o botão Detectar na página.

Atalhos: Alt+Shift+E explica a seleção, Alt+Shift+D dá uma dica. Para mudar, abra opera://extensions/shortcuts.
