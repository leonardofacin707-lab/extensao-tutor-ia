Questão 1 — Lógica

Questão 2 — Redes de computadores

Uma rede usa o endereço 192.168.10.0/26. Quantos endereços de host utilizáveis existem em cada sub-rede?

Questão 3 — Segurança da informação

Um sistema monta consultas assim:

sql = "SELECT * FROM usuarios WHERE login = '" + login + "'"

Qual é a forma mais adequada de evitar SQL Injection nesse código?

Questão 4 — Python

Qual é a saída do programa abaixo?

def adiciona(item, lista=[]):
    lista.append(item)
    return lista

print(adiciona(1))
print(adiciona(2))
